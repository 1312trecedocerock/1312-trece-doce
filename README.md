# 1312 Trece Doce — Web oficial

Sitio web oficial de la banda de hard rock **1312 Trece Doce** (Villa Libertad, Gral. San Martín, Bs. As.).

## Estructura

- `index.html` — la página principal
- `assets/` — imágenes (logo, hero, lettering)

## Cómo editar

Este sitio es HTML/CSS puro, sin dependencias. Para verlo, abrí `index.html` en cualquier navegador.

## Publicación

Publicado con Cloudflare Pages. Cada cambio en la rama `main` se despliega automáticamente.
